# 娜娜教授研究島 V1.3

完整 GitHub Pages 靜態網站。保留 V1.2 原始圖像、三位島主、五座島嶼及中英文功能，新增 22 筆官方書目研究卡片，與原有內容合併。

## 上傳方式
請將本資料夾**內部**的 index.html、app.js、data.js、styles.css、assets 資料夾上傳至 GitHub Repository 的根目錄（不要額外包一層 v1.3 資料夾）。
若 GitHub 網頁上傳無法覆蓋同名檔案，使用 Edit 或 GitHub Desktop 進行取代。
