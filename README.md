# 娜娜教授研究島 V1.4 — 角色互動版

這是完整的 GitHub Pages 靜態網站，保留 V1.3 的論文資料、島嶼圖、三位島主造型與中英文切換。

## V1.4 新功能

- 點選首頁「開始對話」或右下角浮動 Elara，開啟三位島主的預設互動對話。
- 娜娜、Elara：三題統計小測驗，答題後顯示解說與分數。
- 華仔：行銷心理小問題。
- 從對話前往娜娜／華仔研究館、統計冒險島、Another Me 與研究圖書館。
- Elara 浮動效果；支援關閉、鍵盤 Escape、焦點循環及偏好減少動態效果。
- 中英文介面；完全靜態，不需 API 金鑰或 AI 費用。

## 安裝

1. 解壓縮 ZIP。
2. 將 ZIP 內**檔案與 assets 資料夾**放在 GitHub repository 根目錄（與原本 index.html 同一層），同名檔案更新覆蓋。
3. 在 GitHub Pages 部署完成後，重新整理網站（Mac Safari 可按 Command + Shift + R）。
4. 點選「開始對話」，再試試右下角飛行的 Elara。

## 學術與技術說明

本次**不更動 V1.3 的論文書目及驗證狀態**；角色對話是原創腳本，並非即時 AI。沒有外部 API、帳號登入或訊息收集。原本的學術查證備註保留。

新增 `interactions.js`，既有 `app.js` / `data.js` / `styles.css` 及圖片保留並擴充。若要關閉浮動角色，可點選其旁的 ×。
