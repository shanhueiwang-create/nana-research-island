# 娜娜教授研究島 V2.6｜跨島巡遊完整版

以 V2.5 為基礎。娜娜與華仔在首頁地圖的不同島嶼間沿預設路線行走，不再侷限於一個小型動畫區域；保留原本四格步伐、角色對話、Elara 巡遊、星星尋寶、證書、圖書館與 DOI 資料。

## 部署
解壓縮並上傳根目錄所有檔案，以及 assets 資料夾內檔案至 GitHub 倉庫對應路徑。請勿把外層資料夾當作網站根目錄。

## 測試
首頁觀察 20–40 秒，娜娜與華仔應會從原本島嶼走向中央研究總部、停下說話，再返回。點擊人物應可對話。手機版採縮短路線。偏好減少動畫者會停留在原地。

## 限制
本版沿地圖百分比座標行走，並非依地圖橋面做碰撞偵測；部分路段視覺上可能像穿越空中。真正貼合橋面需要另行標定路徑。
