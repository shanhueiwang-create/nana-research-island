# 娜娜教授研究島 V1.5 — 星光巡遊版

本版保留 V1.4 所有研究館、論文資料、三位島主、對話與小測驗。

## 新增功能
- Elara 在首頁每隔一段時間依序飛往五座島嶼地圖熱點，沿途留下短暫星光。
- 到站時說出中英雙語導覽小語；點擊 Elara 仍可開啟既有三島主對話。
- 右下角 `⏸ / ▶` 可暫停或繼續巡遊，`×` 可隱藏角色。
- 切換頁面、打開對話、切換瀏覽器分頁時停止飛行，避免干擾。
- 偏好減少動態效果的裝置預設不啟動飛行。
- 不使用 AI API，不會產生 AI API 費用。

## GitHub Pages 更新
解壓 ZIP 後，上傳**所有檔案和 assets 資料夾內的內容**到既有 GitHub 倉庫根目錄，覆蓋同名檔案並新增 `flight.js`。不要多包一層資料夾。

## 測試
在首頁等待約 4 秒，看 Elara 是否從右下角飛向島嶼；可用暫停／播放切換。點她應開啟對話。離開首頁後應停止飛行。

研究論文書目尚未在此版本重新查證，留待後續版本處理。
