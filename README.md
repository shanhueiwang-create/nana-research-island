# 娜娜教授研究島 V2.2｜角色與尋寶介面修正版

以 V2.1 完整網站為基礎，保留圖書館、島主介紹、Elara 巡遊與五島尋寶進度。

## 修正
- 娜娜、華仔散步角色使用透明背景的小型 Q 版圖，不再直接移動大型人物介紹卡。華仔保留深藍帽、黑框眼鏡與咖啡。
- 星星問答採畫面中央的高層級彈窗，避免在左下角被裁切。
- 證書使用獨立 A4 橫式列印根節點，只輸出證書內容，保留輸入姓名、五顆星星與日期。
- 原本 V2.1 已收藏的星星保留在相同瀏覽器的 localStorage。

## 部署
將 ZIP 解壓後的檔案放在 GitHub 倉庫根目錄，`assets/` 資料夾中的新 PNG 也必須上傳。請勿直接把 ZIP 上傳作為網站首頁。

## 驗收
測試首頁兩位角色大小、對話按鈕、五島題目與證書列印預覽。瀏覽器列印時選擇 A4、橫向，並關閉「頁首與頁尾」。
