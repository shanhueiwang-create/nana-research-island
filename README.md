# 娜娜教授研究島 V2.1｜完整整合版

本版直接由 V1.9 完整檔案延伸，**包含 V1.8 及更早版本保留的論文資料、五座島嶼、三位島主、華仔帽子及黑框眼鏡造型、Elara 星光巡遊、人物散步、角色對話**。

## 新增功能
- 五座島嶼各有一顆研究靈感星星（研究總部、國際企業島、統計冒險島、AI 與另一個我、華珊派夢想學院）。
- 每座島需回答一題知識問題才能獲得星星，答錯可重試，答對提供解釋。
- 蒐集進度儲存於瀏覽器 localStorage，不上傳個資或學生成績。
- 蒐集五顆星星後解鎖「研究島探險家證書」，可填暱稱並透過瀏覽器列印／另存 PDF。
- 中英文切換、手機版與減少動態效果偏好支援。

## GitHub Pages 上傳
1. **只需上傳這個 V2.1 完整整合版**；不需要依序上傳 V1.9、V2.0。
2. 將 ZIP 解壓縮，開啟其中網站資料夾，將 `index.html`, `styles.css`, `app.js`, `data.js`, `interactions.js`, `flight.js`, `walkers.js`, `quest.js` 與 `assets/` 內容上傳至 repository 的正確路徑。
3. 在 GitHub 上確認 `quest.js` 位於 `index.html` 同一層；`assets` 內的圖檔仍位於 `assets/`。
4. Commit changes，等待 Actions / Pages 部署成功後刷新網頁。

## 注意
- 這是**遊戲紀念證書**，非官方學歷、學分、身分或修課認證。
- localStorage 可能在無痕模式、清除網站資料或更換裝置後消失。
- 目前沒有後端，因此不具防作弊與跨裝置同步功能。
- 論文書目沿用 V1.9 的資料；未重新驗證每一筆 DOI。
